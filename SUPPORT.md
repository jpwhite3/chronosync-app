# Support

ChronoSync is an early-stage project without guaranteed support response times.
The following paths make questions and reports easier to handle.

## Using the App

Start with the [user guide](docs/README.md), which covers iPhone, web/PWA, Mac,
shared roles, local data, recovery, and troubleshooting with screenshots.

## Developing ChronoSync

Use the [developer handbook](docs/development/README.md) for prerequisites,
commands, architecture, tests, relay setup, releases, and common failures.
Run `make doctor` and check
[developer troubleshooting](docs/development/troubleshooting.md) before opening
an issue.

## Report a Bug

Use the repository's bug-report issue form. Include:

- the commit or app version;
- device, OS, browser, and Flutter version as applicable;
- concise reproduction steps, expected behavior, and actual behavior;
- sanitized logs and screenshots;
- the smallest relevant test case, when possible.

Never attach invitation URLs, capability tokens, room secrets, raw device IDs,
or sensitive plan content. If a report may have security impact, stop, read
[SECURITY.md](SECURITY.md), and establish a private channel before sharing
details.

## Request a Feature

Use the feature-request issue form and describe the user problem before the
proposed solution. Note the affected platforms and roles, accessibility or
privacy constraints, and alternatives considered.

Questions requiring private operational support are not currently offered.
